Margaux's Nail Polish – swatch crop update

Before uploading this version to GitHub, run SUPABASE_SWATCH_CROP.sql once in Supabase SQL Editor.

The polish editor now lets you: upload a swatch photo, drag the photo inside a square crop area, zoom in/out, reset the crop, and save the crop settings. The original photo remains stored and is still shown when you click a polish.

Replace index.html and the frames folder in your GitHub repository. Keep your existing Supabase data and permissions.
